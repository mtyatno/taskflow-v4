# Note ToC & H4-H6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tambah ToC (Table of Contents) otomatis di sisi kanan NoteModal berdasarkan heading H1-H6 dari isi note, sekaligus perluas `renderMarkdown` dan `NoteToolbar` untuk mendukung H4, H5, H6.

**Architecture:** Tiga perubahan di `static/index.html`: (1) `renderMarkdown` diperluas untuk H4-H6 dengan `id="note-h-N"` pada setiap heading element; (2) `NoteToolbar` dapat tiga tombol H4/H5/H6 baru; (3) fungsi `extractHeadings(content)` + komponen `NoteToc` baru, diintegrasikan ke `NoteModal` sebagai panel 160px di kanan area konten. Tidak ada perubahan backend.

**Tech Stack:** React (inline SPA, `static/index.html`), `renderMarkdown` (line ~5421), `NoteToolbar` (line ~5503), `NoteModal` (line ~5551).

- [ ] **Step 2: Tambah `extractHeadings` sebelum `function NoteModal(`**

Cari baris `function NoteModal(` (sekitar baris 5551). Tambahkan tepat sebelumnya:

```javascript
    function extractHeadings(content) {
      const headings = [];
      let idx = 0;
      for (const line of content.split("\n")) {
        const m = line.match(/^(#{1,6}) (.+)/);
        if (m) headings.push({ level: m[1].length, text: m[2].trim(), idx: idx++ });
      }
      return headings;
    }
```

- [ ] **Step 3: Tambah komponen `NoteToc` sebelum `function NoteModal(`**

Tepat setelah `extractHeadings`, tambahkan:

```jsx
    function NoteToc({ items, previewRef }) {
      const [activeIdx, setActiveIdx] = React.useState(null);

      const handleClick = (item) => {
        setActiveIdx(item.idx);
        const el = document.getElementById(`note-h-${item.idx}`);
        if (el) el.scrollIntoView({ behavior: "smooth", block: "start" });
      };

      return (
        <div style={{
          width: 160, flexShrink: 0,
          borderLeft: "1px solid var(--border)",
          paddingLeft: 10,
          overflowY: "auto",
          maxHeight: "100%",
          scrollbarWidth: "thin",
          scrollbarColor: "var(--border) transparent",
        }}>
          <div style={{ fontSize: 10, fontWeight: 700, color: "var(--text-light)", textTransform: "uppercase", letterSpacing: 1, marginBottom: 6, paddingLeft: 6 }}>
            Isi
          </div>
          {items.map(item => (
            <span
              key={item.idx}
              className={`note-toc-item${activeIdx === item.idx ? " active" : ""}`}
              style={{ paddingLeft: 6 + (item.level - 1) * 10 }}
              onClick={() => handleClick(item)}
              title={item.text}
            >
              {item.text}
            </span>
          ))}
        </div>
      );
    }
```
